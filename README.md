# Seasonal Agriculture Performance Analysis 🌾📊
A Data-Driven Study on Crop Yield, Water Efficiency & Farm Economics.

## 📌 Project Overview
Executed under the **VOIS AICTE Internship Batch 1 (2026-2027)** in **Data Visualization**.
This project analyzes **4,000 multi-regional farm records** across 8 Indian states (Kharif, Rabi, Zaid seasons).

## 🔑 Key Findings
- **Kharif Dominance:** Highest average yield (5.64 t/ha) and profit (₹1.79 Lakhs).
- **Irrigation Efficiency:** Drip irrigation achieves 6.27 t/1000m³ efficiency, boosting profit by ~200% over flood irrigation.
- **Cash Crops vs Grains:** Sugarcane (₹8.17L) and Chilli (₹7.51L) dominate profitability, whereas staple grains faced negative margins.
- **Pest Risk:** Kharif exhibits peak pest risk (54.5%) linked to >65% humidity.
